# PowerShell-Ciberseguridad

"AuditoriaBasica" incluye dos funciones cuya finalidad es mostrar las cuentas locales habilitadas  que no tienen una ultima fecha de inicio de sesion, la otra funcion muestra los servicios en ejecucion que no sean de Windows. El script "auditoria_usuarios" identifiqua usuarios locales en el sistema y genera una alerta si alguno está deshabilitado o nunca ha iniciado sesión. Estos scipts sirven para poder detectar posibles programas maliciosos.Aprendi el uso de funciones basicas en PS durante el desarrollo de este
